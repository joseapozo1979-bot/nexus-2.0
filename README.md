# NEXUS 2.0

## Unified Infrastructure Operations Center

NEXUS is a unified infrastructure operations dashboard designed to centralize IT monitoring, service management and operational telemetry into a single interface.

The platform integrates enterprise technologies such as Zabbix, GLPI, MariaDB and MongoDB, providing administrators with a centralized operational view of their infrastructure.

---

## Features

- Unified Operations Dashboard
- Zabbix Monitoring Integration
- GLPI Ticket Management
- Asset Inventory
- MongoDB Telemetry
- Remote Monitoring Agent
- User & Role Management
- Security Audit
- Configuration Center
